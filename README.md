# RESEE HER 🌿
### AI-Powered Environmental Discovery

**Look again. She's changing.**

RESEE HER is an environmental discovery platform that helps people explore places, understand environmental change, discover the stories behind nature, and turn awareness into meaningful action.

Rather than presenting nature as just a destination, RESEE HER encourages people to reconnect with the environment through exploration, storytelling, AI-assisted guidance, and practical actions.

🌐 **Live Website:** https://environmental-discov-twzf.bolt.host

## ✨ Features

- **Explore:** Search for places around the world and begin discovering their environmental context.
- **Her Story:** Interact with an AI-powered guide for educational information about environmental topics.
- **Resee:** Revisit how we perceive and connect with the natural world.
- **Understand:** Explore environmental concepts and learn about human impacts on nature.
- **Respond:** Discover practical ways to support environmental awareness and action.

## 🧠 How It Works

RESEE HER combines an interactive web experience with AI-assisted environmental education.

1. Users search for a place or select a suggested destination.
2. The platform helps them explore environmental context and related information.
3. The AI guide provides educational responses to environmental questions.
4. Users learn about environmental change and discover possible actions.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- A modern web browser
- The required API and Supabase configuration for AI features

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/40273mousyasriv-sketch/resee-her.git
   ```

2. Enter the project directory:

   ```bash
   cd resee-her
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables using the project's existing configuration and Supabase Edge Functions.

   **Never commit real API keys, passwords, or secret credentials to GitHub.** Use a local environment file for development and configure server-side secrets securely in Supabase.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in your terminal.

> Exact environment variable names and deployment steps depend on the current project configuration. Review the source code before configuring the application.

## 🔐 Security

- Do not commit `.env` files or private credentials.
- Keep AI provider keys on the server side, such as in Supabase Edge Function secrets.
- Apply appropriate access controls and security policies to backend services.
- Never expose service-role keys in frontend code.

## 🌍 Environmental Information Disclaimer

RESEE HER provides educational context and general guidance. It does **not currently claim to monitor environmental conditions in real time**. Information presented should not be treated as live environmental measurements or official environmental assessments.
